# 参数化套件模式

默认产出的一次性套件只解决用户这次给的具体值。**参数化模式**把它做成可复跑用例：同一份 `.robot`，换 `--variable` 就能跑同类任务。

## 何时启用

用户说"做成可复用的用例""参数化""以后换个关键字/城市/日期还能跑""接到 Jenkins 里定时跑"，或者任务本身明显是重复性的（每天查同一站点的一个指标）。

## 契约

### 1. `*** Variables ***` 存默认值，等于本次任务的值

```robot
*** Variables ***
${关键字}        机械键盘          # 来源：用户原话“搜机械键盘”
${最低价}        300
${最高价}        500
${排序方式}      销量
${目标URL}       https://search.example.com    # 站点入口，非参数
```

- 站点入口、选择器策略这类**不变**的东西不进变量表（写死在关键字里即可）。
- 变量名用中文，与 `--variable` 的键同名。

### 2. 用例调用带 `[Arguments]` 的关键字

```robot
*** Test Cases ***
商品 按关键字与价格区间筛选并取最低价
    [Documentation]    参数化用例：默认值复现原任务
    [Tags]    冒烟测试
    商品 搜索并筛选    ${关键字}    ${最低价}    ${最高价}    ${排序方式}

*** Keywords ***
商品 搜索并筛选
    [Documentation]    在商品列表页按关键字与价格区间筛选，并按指定方式排序
    ...    ---
    ...    入参：
    ...    - `关键字`：搜索关键词
    ...    - `最低价`：价格下限（元，整数）
    ...    - `最高价`：价格上限（元，整数）
    ...    - `排序方式`：站点排序控件上的可见文本，如“销量”
    ...    ---
    ...    出参：
    ...    - 无
    ...    ---
    ...    示例：
    ...    | 商品 搜索并筛选 | 机械键盘 | 300 | 500 | 销量 |
    ...    ---
    ...    创建用户：<你的名字>
    ...    创建时间：<yyyy-MM-dd>
    [Arguments]    ${关键字}    ${最低价}    ${最高价}    ${排序方式}
    网页端PW 打开浏览器    ${目标URL}    是否无头模式=True    最大等待时间=30s
    网页端PW 等待并输入文本    //input[@name='q']    ${关键字}
    网页端PW 等待并点击元素    //button[text()='搜索']    最大等待时间=10s
    # …按 ${最低价} ${最高价} ${排序方式} 操作站点的筛选与排序控件…
    Browser.Take Screenshot    ${OUTPUT DIR}${/}screenshots${/}CP1_筛选已应用.png    fullPage=False
```

### 3. 运行时覆盖

```pwsh
# 单个变量（名称:值，中文与空格建议整体加引号）
python -m robot --variable "关键字:静音鼠标" --variable 最低价:100 `
  --outputdir .tmp\<task_id>\final_runs\run_alt 01测试用例\<套件>.robot

# 多组参数：写参数文件，每行一个选项
python -m robot --argumentfile .tmp\<task_id>\args.txt 01测试用例\<套件>.robot
```

`args.txt` 示例：

```text
--variable 关键字:静音鼠标
--variable 最低价:100
--variable 最高价:200
--outputdir .tmp/task_001/final_runs/run_alt
```

## 验收（缺一不可）

1. **不带任何 `--variable`** 在 `final_runs/run_1/` 复现原任务并通过——默认值就是原任务的值。
2. **换一组值**在 `final_runs/run_alt/` 跑通，证明参数真的生效（不是被写死覆盖）。
3. `*** Variables ***` 里每个参数都在关键字的 `[Arguments]` 与 `[Documentation]` 的入参段出现，含义、单位、允许值写清楚。
4. 报告里能看到生效值：把关键参数用 `Log    ${关键字} / ${最低价}-${最高价}` 打一条，或在截图里能看出筛选条件。
5. 报告里给用户一条可直接复制的复跑命令。

## 注意

- 参数值含空格、中文、`:` 时，`--variable "名称:值"` 要整体加引号；值里再出现 `:` 时用 `--variable 名称:值:带冒号` 会截断，改用参数文件。
- 不要把"站点入口 URL"参数化到能指向任意站点的程度——那会让选择器全部失效，属于假参数化。
- 参数化不改变语法门禁：`VAR` / `RETURN` / `IF … END` 照样要守。
